---

1. Operadores de Comparacao

 = (Igual): `idade = 20`

 <> ou != (Diferente): `idade <> 20`

 > (Maior que): `idade > 20`

 >= (Maior ou igual): `idade >= 20`

 < (Menor que): `idade < 20`

 <= (Menor ou igual): `idade <= 20`

---

2. Exemplos Praticos de Filtros

 Igual (=): SELECT * FROM alunos WHERE turma = 755;

 Diferente (<> ou !=): SELECT * FROM alunos WHERE ativo = 1;

 Maior que (>): `SELECT * FROM alunos WHERE idade > 20;

 Menor que (<): `SELECT * FROM alunos WHERE idade < 20;`

 Maior ou igual (>=): `SELECT * FROM alunos WHERE nota >= 8.0;`

 Menor ou igual (<=): `SELECT * FROM alunos WHERE nota <= 7.0;`

 Entre valores (BETWEEN): `SELECT * FROM alunos WHERE idade BETWEEN 20 AND 23;`

 Lista de valores (IN): `SELECT * FROM alunos WHERE turma IN (755, 315);`

 Texto parcial (LIKE): `SELECT * FROM alunos WHERE nome LIKE 'A%';` ( `%` = comeca com A; `%...%` = contem a letra; `%...` = termina com a letra )

 Condicoes multiplas (AND): `SELECT * FROM alunos WHERE turma = 755 AND nota >= 9.0;`

 Condicoes alternativas (OR): `SELECT * FROM alunos WHERE turma = 755 OR nota >= 9.0;`
